# Задача 10.4 — «План маршрутизації»

## Конфігурація

У проєктних налаштуваннях `.claude/settings.json` головна модель задана як `claude-sonnet-5-5`, а змінна `CLAUDE_CODE_SUBAGENT_MODEL` — як `claude-haiku-5-5`. Примусове перевизначення `CLAUDE_CODE_SUBAGENT_MODEL_FORCE` не ввімкнене. Агент `change-reviewer` має власне `model: sonnet`, тому продовжує працювати на Sonnet.

| Тип роботи | Модель | Чому |
|---|---|---|
| Основна розробка, планування й рішення з кількома залежностями | Sonnet 5.5 | Залишає складні міркування в головній сесії. |
| Обмежене делеговане читання й підсумки | Haiku 5.5 | Дешевший слот для вузьких задач із чітким обсягом. |
| Рев'ю змін | Sonnet (`change-reviewer`) | Явно закріплена модель рев'ювера збережена. |

## Замір до і після

Однакова read-only задача в обох окремих запусках: попросити субагента прочитати `src/hp.ts` і повернути рівно три пункти про валідацію, пошук/оновлення гравця та HP-дії. Головну модель зафіксовано на Sonnet 5.5; інструменти, режим планування, MCP-конфігурація та ліміт запуску були однаковими.

| Маршрут | Input | Cache read | Cache write | Output | Оцінка вартості CLI |
|---|---:|---:|---:|---:|---:|
| До: Sonnet 5.5 + субагент успадковує Sonnet | 8 | 19,995 | 7,123 | 1,346 | $0.03959 |
| Після: Sonnet 5.5 + Haiku 5.5 субагент | 8 | 18,441 | 8,696 | 1,489 | $0.02500 |

**Різниця:** другий маршрут коштував за оцінкою CLI на **\$0.01459 (36.9%) менше**.
Загальна кількість токенів у цих категоріях була близькою: 28,472 до і 28,634 після. Витрати після перемикання розподілилися так: Sonnet — $0.02395, Haiku — $0.00105.

## Висновок та обмеження

Для короткого делегованого підсумку Haiku знизив оцінену вартість, хоча сумарна кількість токенів майже не змінилася. Це один контрольований замір, а не гарантія економії для довших задач: у Haiku окремий кеш, і перший запит субагента записував його префікс (4,554 cache-write токени загалом; 3,144 прочитано під час наступного запиту). Суми виведені Claude CLI з `costBasis: list`; це оцінка за прайсом, не фактичне списання з плану Claude Pro.
