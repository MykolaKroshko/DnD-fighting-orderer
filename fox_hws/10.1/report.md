# Задача 10.1 — «Інвентаризація сетапу»

## Метод

Вимірювання зроблено Claude Code 2.1.326, Sonnet 5.5. Для звичайних зрізів використовувався однаковий короткий запит: `Reply with exactly: OK`. Для адресного правила — однаковий запит із читанням `src/components/CombatStage.tsx`. Ефективний вхідний обсяг рахувався як `input_tokens + cache_creation_input_tokens + cache_read_input_tokens`.

Порівнював `--safe-mode` із повною конфігурацією, а потім вимикав по одній фічі лише для одного запуску: через CLI override або тимчасове переміщення відстежуваного файла. Файли `CLAUDE.md`, правила та агент після кожного заміру відновлені з Git.

Сума нижче — вхідні токени оброблених запитів; виміри з кількома ходами рахують усі ходи однакового завдання.
